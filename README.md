# 《流星号に乗って》简体中文汉化补丁

适用于 **Underground Campaign** 出品的日文游戏《流星号に乗って》的玩家自制简体中文汉化补丁。

> 本仓库**只包含汉化文本 `src.fwd` 一个文件**，不含任何原游戏文件。
> 你需要自备日文原版游戏本体（约 1.3 GB）。

- 把游戏正文全部汉化成简体中文（替换文本数据 `src.fwd`）
- 附带修复：让你避开会把存档改坏的「汉化版引擎」（见下方）

## 安装方法

1. **确认游戏目录里用的是原版引擎** `star.exe`
2. 把 `src.fwd` 复制到游戏目录
3. 提示「是否覆盖」时选 **覆盖**
4. 双击 `star.exe` 开始游戏
 **请安装QuickTime 7.7.9这个版本在我的设备上运行不崩溃**



---

## ⚠️ 不要用 "Famous Writer v3.10 汉化版" 引擎

网上流传的那个引擎（`Famous Writer v3.10汉化版.exe`，约 4,276,286 字节）是被改过的。
它虽然能把菜单栏汉化，但**把游戏的存档逻辑改坏了**，会导致：

- 存档后回到标题界面再读档 → 同行同伴会丢失、变成默认角色
- 存档后读档 → DRIVE（开车）功能卡死，车一直开但进不了下一个地点

实测**原版引擎完全支持 UTF-8**，中文正文显示一切正常。

**代价**：引擎自带的菜单栏（文件 / 显示 / 帮助）和少数对话框按钮仍是日文。
这部分字符串编译在 exe 里，不在游戏数据里，改动风险大，故不处理。

## 为什么本仓库只有 4.4 MB

原本的补丁包里有三个文件，但经逐字节比对：

| 文件 | 实际性质 | 是否汉化内容 |
| --- | --- | --- |
| `src.fwd` | 与原版不同（1,076,684 字节有差异） | ✅ **是**，唯一的汉化文件 |
| `star.exe` | 与游戏 2007 年原版引擎**逐字节完全相同** | ❌ 纯原版游戏文件 |
| `FmWr.ini` | 与游戏原版配置**逐字节完全相同** | ❌ 纯原版游戏文件 |

后两个文件对你来说本来就是现成的——它们就在你自己的游戏目录里。
所以本仓库只分发真正属于汉化成果的 `src.fwd`。

## 常见问题

**Q：只有 4.4 MB，是不是缺图片和语音？**
A：不是缺。本补丁**只替换文本**，图片和音频沿用原版游戏本体。
汉化只改文本是有意为之——重打包 1.3 GB 的资源既没必要，也不该由汉化补丁分发。

**Q：为什么菜单栏还是日文？**
A：见上文「不要用汉化版引擎」。菜单字符串编译在 exe 里，改它风险大且会连带改坏存档逻辑。

**Q：覆盖 `src.fwd` 会不会弄坏游戏？**
A：不会。原版 `src.fwd` 建议先备份一份，想还原日文版时覆盖回去即可。
